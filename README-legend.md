# Легенда символов карты — установка (v1.0)

## Что сделано

Добавлен **сворачиваемый блок «🎨 Легенда карты»** под самой картой,
внутри вкладки «🗺️ Карта». Внутри — 13 пунктов с описанием всех
символов, которые появляются на карте:

1. Границы стран
2. Столица (щит с короной)
3. Подпись страны (Serif-плашка)
4. Игрок онлайн (зелёная рамка)
5. Игрок оффлайн (последняя позиция)
6. Недавняя битва (пульсирующая красная точка)
7. Источник света (ночью, маска 5×5)
8. Топографические контуры
9. Туман войны (пергамент)
10. Координаты (по краям)
11. Компас-роза
12. Морские змеи (декорация)
13. Дороги дипломатии (5 типов линий)

Блок сворачивается кликом по заголовку, состояние сохраняется в
`localStorage` — если свернул, останется свёрнутым после перезахода.

## Как применить

### 1. `legend.css`

Залить новый файл `legend.css` в корень репозитория (рядом с `style.css`).

В `index.html` в `<head>` добавить после `<link rel="stylesheet" href="style.css?v=5.3">`:

```html
<link rel="stylesheet" href="legend.css?v=1.0">
```

### 2. `legend-block.html`

В `index.html` найти:

```
<div class="map-legend" id="map-legend"></div>
```

Сразу после него вставить всё содержимое `legend-block.html` (это
`<section class="map-symbol-legend" id="map-symbol-legend"> ... </section>`).

### 3. `patch-legend.js`

Открыть `app.js`, добавить в конец функцию `initMapSymbolLegend()`.

Затем найти в `DOMContentLoaded`:

```
['initTabs','initSortTabs','initMapControls','initMapFullscreen','initCommandCopy',
 'initCommandSearch','initPlayerControls','initModalControls'].forEach(function (fn) {
```

Заменить на:

```
['initTabs','initSortTabs','initMapControls','initMapFullscreen','initCommandCopy',
 'initCommandSearch','initPlayerControls','initModalControls','initMapSymbolLegend'].forEach(function (fn) {
```

### 4. Бамп версии

`version.txt` — `5.10`. Плюс в `app.js` поменять `APP_VERSION` на `'v5.10'`.
Плюс в `index.html` поменять `app.js?v=5.9` → `app.js?v=5.10`.

### 5. Проверка

Открыть вкладку «🗺️ Карта», прокрутить вниз. Под картой, под старым
`#map-legend` (там где цветные точки стран), появится новая секция
«🎨 Легенда карты». Клик по заголовку — сворачивает/разворачивает.

В консоли F12 при загрузке должно быть:

```
[Sovereignty] v5.10 DOMContentLoaded
```
