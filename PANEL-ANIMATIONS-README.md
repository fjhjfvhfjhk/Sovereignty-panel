# Панель · Фаза 1 анимаций

Дата: 09.10.2026

Первая фаза внедрения анимаций из lux-7-демо. Все эффекты — CSS + лёгкий JS, без библиотек.

## Что добавлено

### Ambient glow (`#ambient`)
Светящийся слой за контентом, который меняет цвет в зависимости от состояния мира:

| Состояние | Цвет | Условие |
|---|---|---|
| default | индиго `#6366f1` | мира нет войны |
| `war` | красный `#ef4444` | есть страны с `active_wars > 0` |
| `peace` | зелёный `#10b981` | (задел — пока не активно) |
| `event` | фиолетовый `#a88be8` | (задел — пока не активно) |

Состояние выставляется автоматически в `panel-ambient.js` при каждом обновлении JSON.

### Particle layer (`#particles`)
60 светящихся точек дрейфуют по фону, цвет плавно интерполируется к текущему ambient. Отключается через `prefers-reduced-motion`.

### Shine-заголовок
`Sovereignty` в шапке теперь с проезжающим градиентом (белый → лаванда → белый). Цикл 8с.

### Card hover shine
При наведении на `.stat-card` и `.player-card` по диагонали проезжает световая полоса в цвет ambient.

### Ripple
Клик по `.nav-btn`, `.map-btn`, `.tab`, `.btn`, `.player-modal-btn`, `.map-layers-close/restore` создаёт волну от точки клика.

### Number pop
`.stat-value` и `.num` «подпрыгивают» при изменении значения. Триггерится через MutationObserver — не требует правок app.js.

### Pulse-бейджи
- `#online-badge` пульсирует красным, если есть активные войны (`active_wars > 0`).
- `#updated-badge` пульсирует зелёным, если данные свежие (<60 сек).

### Screen transitions
Смена вкладок теперь с slide-up + fade.

### Event log stagger
Записи в `#event-log-list` появляются каскадом (delay = idx × 30мс).

## Файлы

| Файл | Что делает |
|---|---|
| `panel-animations.css` | Все стили анимаций |
| `panel-ambient.js` | Ambient + particles + ripple + pop + pulse-бейджи |
| `index.html` | Подключение новых файлов + `<div id="ambient">` + `<canvas id="particles">` |
| `version.txt` | 5.12 |

## Как применить

1. Залить `panel-animations.css` и `panel-ambient.js` в корень репо.
2. Заменить `index.html`.
3. Обновить `version.txt` → `5.12`.
4. **Ctrl+Shift+R** в браузере.

## Проверка

Открой панель, посмотри:

1. **Заголовок** — по буквам «Sovereignty» проезжает светлая полоса (цикл 8с).
2. **Фон** — за контентом мягкое индиго-свечение, чуть дышит. По фону плавают светящиеся точки.
3. **Наведи** на статкарточку — по диагонали пробегает светлая волна.
4. **Кликни** любую кнопку — от точки клика расходится ripple.
5. **Смотри на числа** — при обновлении JSON (раз в 5 мин или по кнопке «Обновить») значения «подпрыгивают».
6. **Бейдж онлайн** — если в JSON есть страны с `active_wars > 0`, бейдж пульсирует красным.
7. **Открой другую вкладку** — контент появляется с fade + slide-up.

## Откат

Если что-то не понравится:

1. Удалить `<link rel="stylesheet" href="panel-animations.css?v=1.0">` из `index.html`.
2. Удалить `<script src="panel-ambient.js?v=1.0"></script>`.
3. Удалить `<div id="ambient">` и `<canvas id="particles">`.
4. Вернуть `version.txt` → `5.11`.

Всё вернётся к прежнему виду. Никакие другие файлы не тронуты.
